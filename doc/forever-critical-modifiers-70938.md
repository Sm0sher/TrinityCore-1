# Заряжаемые усиления критического удара — 70938

Блок 162: **2753 → 2739 сообщений**, новых нет; карантин не добавлялся.
Добавлены 14 правил `spell_proc` для чистых заряжаемых модификаторов
критического шанса (ауры 107/108, операция 7). Эффекты, шанс, число зарядов,
исходные события и перезарядка заклинаний не меняются.

Маски семейства берутся из четырёх нативных слов SpellEffect 70938 с переводом
знаковых значений в uint32. Для каждой маски проверено наличие нативных целей.
Фаза HIT (2) нужна, поскольку критический шанс вычисляется при обработке
попадания; CAST из предыдущего пакета сюда не переносится. Атрибут
REQ_SPELLMOD (8) требует, чтобы аура была зарегистрирована в `m_appliedMods`
текущего заклинания. Это также сохраняет существующую логику Player, которая
при двух усилениях +100% применяет и расходует только одно.

События ограничены нативными исходящими заклинаниями/способностями. Маски
с автоударом ближнего боя и SQL-переопределённые записи исключены. Дальняя
автоатака проходит через Spell и проверку семейства. HitMask 0 сохраняет
штатный допуск попаданий (обычное, критическое, поглощение), а не требует
исключительно критического результата. Нет связанных скриптов или
серверных переопределений эффектов у включённых заклинаний.
