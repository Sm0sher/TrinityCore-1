# Блок 160: расход зарядов модификаторов заклинаний, Forever 70938

Рабочий перезапуск: **2 809 → 2 782 сообщения DBErrors**, устранено **27**,
новых сообщений нет. Группа аур без явного правила срабатывания уменьшилась
с 231 до **204** сообщений. Это настройка серверной механики, без карантина
предметов, NPC или заданий.

## Причина и исправление

У выбранных аур есть заряды и native-флаги событий, но только эффекты
`ADD_FLAT_MODIFIER` / `ADD_PCT_MODIFIER`. Генератор SpellMgr не добавляет для них
автоматическое правило. Player::ApplyModToSpell записывает применённую ауру в
`m_appliedMods`, а Aura::GetProcEffectMask использует это множество для проверки
`PROC_ATTR_REQ_SPELLMOD`. Поэтому отсутствующее правило мешает штатному механизму
расходования зарядов.

Добавлены **27** положительных записей `spell_proc`. Они относятся к изменению
времени произнесения, восстановления и процентной стоимости ресурса. Среди
выбранных ID — 12043, 12536, 16166, 16188, 17116 и 18708; полный список находится
в `contrib/forever-audit/70938-charged-modifiers/manifest.json`.

Правила используют фазу успешного применения CAST и требуют, чтобы данная аура
действительно модифицировала это заклинание. Для native-события
`PROC_FLAG_2_CAST_SUCCESSFUL` фаза в SQL оставлена нулевой: загрузчик сам задаёт
CAST, не выдавая предупреждение о неиспользуемой фазе. Все четыре слова семейной
маски взяты из SpellEffect установленного клиента **70938**, включая старшие
биты и четвёртое слово. Отрицательные представления битовых полей приведены
к uint32, смысл битов сохранён.

Шанс, число зарядов, задержка и оба слова флагов событий наследуются из native
данных. Эффекты, стоимость ресурса, величины усилений и клиентские файлы не
менялись. Для всех 27 масок найдены соответствующие семейства заклинаний
в native-данных.

Готовые записи AzerothCore сверены как справочный пример CAST/REQ_SPELLMOD;
их старые трёхсловные маски не копировались. Проверка положительной **конечной**
стоимости ресурса здесь не добавляется: после применения бесплатного каста
стоимость уже равна нулю, но его заряд всё равно должен расходоваться.
Процентные модификаторы с нулевой исходной стоимостью штатно пропускаются в
Player::GetSpellModValues; исходно мгновенные заклинания возвращаются из
SpellInfo::CalcCastTime до применения модификатора времени.

## Границы отбора

Взяты только ауры с положительным количеством зарядов, native-шансом 100%,
ненулевой семейной маской, известным семейством и чистыми эффектами-модификаторами.
У них нет SQL-переопределений эффектов/параметров, serverside-эффектов,
существующей записи `spell_proc` или привязанного скрипта. Доступность всех
использованных native-записей проверена по последним hotfix-статусам.

Пять случаев с плоским изменением стоимости и два случая с составными эффектами
из первоначальной выборки не включены. Критические, периодические и прочие
события HIT требуют отдельной проверки; CAST-правила на них не распространялись.
Значения шанса и произвольные cooldown ради устранения предупреждения не
назначались.
